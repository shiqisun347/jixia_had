# v1.0 产品简报

稷下是桌面优先的人机实时辩论实验平台，支持 1v1 至 5v5 线性赛制、公开房间、真人/Agent 混合席位、Fun-ASR、流式 LLM、Qwen TTS、赛后 AI 裁判和管理员数据管理。

## 用户

- 辩手：注册、入房选席、设备检测、准备、手动发言、自由辩论举手、赛后审阅文字。
- 房主：创建公开房间、选择规则和辩题、管理 Agent 席位、开赛、暂停/恢复/终止。
- 观众：登录后观战，最多 10 人。
- 管理员：管理用户、规则、题目、模型、音色、Agent、比赛和诊断日志。

## 不可变边界

- 同时最多 5 场 RUNNING/PAUSED 比赛；暂停仍占名额。
- 状态、权限、计时和发言权由 Core/MatchActor 权威维护。
- 主持音频在赛制配置阶段预生成；比赛中不临时调用主持 TTS。
- 中间 ASR 只读；用户只能编辑自己的最终文字，后续 Agent 使用最新 display text。
- Agent 中断从动作起点恢复，不做精确音频 seek。
- MVP 不包含视频、移动端专项适配、短信邮件、知识库、联网搜索和自动备份。
