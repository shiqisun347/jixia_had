# 需求引用规则

产品需求只维护在根目录的 `稷下人机自动辩论实验平台需求文档.md`。本文件不复制需求正文，只提供开发时的检查顺序：

1. 先确认用户身份、房间角色和比赛状态。
2. 再确认服务端权威的席位、发言权、计时和上下文版本。
3. 最后确认实时媒体、失败重试、Toast/页面错误和权限边界。

发现本文件与 PRD 不一致时，以 PRD 为准并删除本文件中的过期表述。
