# MVP 上线工程验收记录（2026-08-04）

> 结论：工程链路已接近 MVP 可用；真人语料 180 秒 ASR 已通过，浏览器现场麦克风与 11 音色至少 10 人真人盲听尚未完成，因此不能宣称最终实验门槛全部通过。

## 五场并发

- 环境：目标单机，约 1.9GB RAM、无 swap。
- 首轮：4/5 完赛，1 场 `tts_send_failed`；第六场返回 `409 match_capacity_full`。
- 根因：首次 TTS 失败后自动重试复用了已损坏连接。
- 修复：TTS Provider 错误时按比赛丢弃并关闭连接，重试时建立新连接。
- 复测：5/5 `FINISHED`、5/5 AI 裁判 `SUCCEEDED`，无串场或异常状态；峰值可用内存约 678–742MB，结束后约 757MB。

## 50 路真实 LLM

- 请求：50 路 OpenAI 兼容短流，统一 `LlmCapacityLimiter(50)`，每路要求流式输出。
- 结果：50 成功、0 失败。
- 延迟：P50 2109.3ms，P95 3206.9ms；全部完成 4234.2ms。
- 说明：该结果证明 50 路短请求可用，但不等同于五场长上下文自由辩论下的持续 50 路饱和吞吐。

## ASR 长样本

- 供应商：真实 `fun-asr-realtime`。
- 输入：180000ms 等价 16kHz 单声道 PCM；440Hz 合成信号，不是真人语料。
- task：连续复用同一连接完成 6 个 30 秒 task。
- 首次 interim：各段 54–68ms。
- final：首段 3087ms，其余 128–310ms。
- 风险：首段 final 超过 PRD 1000ms 目标；合成音并不代表真人识别质量。真人 180 秒普通话、CER、漏段和设备差异仍需单独验收。

### 同一真人说话人 180 秒复测

- 来源：AISHELL-1 测试集说话人 `S0770`，27 条带人工转写的 16kHz 真人普通话录音，语音 177.26 秒，尾部补静音至 180.00 秒；AISHELL-1 为 Apache 2.0 开放普通话语料。
- 执行：目标服务器使用项目正式 `FunAsrConnection` 与 `AsrSpeechSession`，按 100ms 帧和真实时间发送，不做离线瞬时灌入。
- 时长：输入、业务报告均为 180000ms；墙钟 182610ms。
- task：7 段，样本数合计 2,880,000，无零文本段；各段约 27.1、25.8、28.7、28.5、28.8、30.0、11.1 秒。
- 延迟：整场首次 interim 228ms；各段首次 interim 27–266ms；final 17–346ms，全部低于 1000ms。
- 质量：参考 411 字，识别 416 字，编辑距离 16，CER 3.89%。
- 结论：真人普通话、短 task 透明轮换和 PCM 完整性通过；浏览器现场麦克风、设备噪声和网络差异仍需一次真人端到端复测。
- 来源链接：[AISHELL-1 论文](https://arxiv.org/abs/1709.05522)、[本次使用的测试集镜像](https://huggingface.co/datasets/TwinkStart/AISHELL-1)。

## TTS 与音色

- 官方来源：阿里云 Qwen-Audio-TTS 音色列表及 2026-07-23 `qwen-audio-3.0-tts-flash` 基础音色 Excel。
- 已核对并配置：10 个 Agent 基础音色、1 个主持基础音色。
- 五路并发：11 个音色分批、最多 5 路并发；首轮 9/11 成功，失败 2 路均在单独重试一次后成功。
- 延迟：首轮成功项首音频 P50 489ms、P95 622ms；完成 P95 1891ms。
- 校准：11/11 真实 Ogg Opus 解码成功；固定文本测得 4.13–5.98 中文字/秒并写入 `voice_profiles.chars_per_second`。
- 产品：管理台提供每个音色的“生成试听”和 `<audio>` 播放；12 个当前启用音色预览均已生成（含早期仍被 Agent 引用的兼容音色）。
- 风险：程序连通性不能代替至少 10 名中文听众的清晰度、自然度和一致性盲听。

### 2026-08-05 码率、限流与盲听包复核

- 官方限流：`qwen-audio-3.0-tts-flash` task 下发上限为 3 RPS。原 5 worker 批量任务在前 31 段成功后出现 `task-failed`，与瞬时超限一致；`jx-core` 已增加 350ms 全局 task 启动间隔，五路仍可同时处于合成/播放状态。
- 码率修复：代码原传 `bit_rate=32000`，与设计和接口的 kbps 单位不符。同一 16.6 秒样本由 328634B 降为 42004B 后，正式 core/jobs 均改为 `bit_rate=32`。
- 正确参数重生：11 音色 × 3 段辩论文本 × `rate=0.9/1.1`，共 66 段、总时长 1203.4 秒、总音频 3108363B、平均 20.66kbps；66/66 经 FFprobe 解码成功。
- 延迟：首音频 min/P50/P95/max 为 257/397/546/607ms；完成延迟为 903/1383/2307/2594ms。33/33 组中 1.1 倍速音频均短于 0.9 倍速。
- 盲听材料：听众压缩包 2922826B，包含 66 段匿名音频、说明、文本和评分表；不含私有 `mapping.csv` 或 `metrics.json`，两文件在服务器权限均为 `0600`。
- 官方资料：[阿里云模型限流](https://help.aliyun.com/zh/model-studio/rate-limit)、[实时语音合成](https://help.aliyun.com/zh/model-studio/realtime-tts-user-guide)。
- 尚未完成：至少 10 名中文听众独立评分，不能用上述工程指标替代主观音质结论。
