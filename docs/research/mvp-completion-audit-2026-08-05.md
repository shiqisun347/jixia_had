## 真人麦克风最短验收流程

1. 登录正式站，创建房间并选择“`MVP 真人 180 秒语音验收`”赛制。
2. 选择辩题，自己占正方一辩，使用 Agent 填补另一席位。
3. 完成 3 秒麦克风录音回放、扬声器确认和网络检测，点击准备并开赛。
4. 出现“轮到你发言了”后手动点击开始发言，使用真实麦克风连续发言，最长 180 秒，可提前结束。
5. 比赛结束后检查文字稿，提交本人审阅文本，并试听本人原始音轨和整场回放。
6. 验收记录应包含首次 interim、final 延迟、segment、录音时长、回放可听性和页面错误状态。

## 盲听最短验收流程

1. 将匿名听众包分别交给至少 10 名中文听众，不提供 `mapping.csv`。
2. 每名听众使用耳机，独立评价 V01–V11 的清晰度、自然度和跨文本/语速一致性。
3. 汇总每份 CSV。通过线为清晰度不低于 4.0、自然度不低于 3.5、一致性不低于 4.0；至少 4 个 Agent 音色和 1 个主持音色通过。
4. 将评分表上传服务器的独立目录后运行：

   ```bash
   python3 scripts/qa/summarize_voice_blind_scores.py scores/*.csv \
     --mapping data/voice-blind-pack/20260804/mapping.csv \
     --output data/voice-blind-pack/20260804/listening-result.json
   ```

   工具会拒绝重复评分、缺失音色、越界分数和不足 10 名听众的数据，只输出汇总均分和最终门槛，不输出听众评论或身份列表。

5. 汇总完成前，不把程序可解码、ASR 可识别或低延迟替代为真人主观音质结论。
