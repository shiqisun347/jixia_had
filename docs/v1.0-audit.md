# v1.0 结构审计

更新时间：2026-08-18

## 已移除

- 001–160b 的中间规格、旧 `MEMORY`、验收截图和导出包已移出项目主目录，不参与 v1.0 开发。
- 本地 `.codex-tmp` 凭据、构建缓存、Storybook/Next 缓存、Python 字节码和临时图像已清理。
- 旧根目录 `readme.md` 已替换为当前 v1.0 README；旧的“基础/认证未完成”说明不再作为入口。
- 管理后台两个原生 `confirm` 已替换为统一可访问 `ConfirmDialog`，避免浏览器原生弹窗阻塞和测试环境差异。

## 保留的模块

- `jx_core.main` 仍保留：OpenAPI 导出和测试需要 import-safe app factory；生产入口仍是 `jx_core.cli`，不是重复启动入口。
- `formal_4v4.py` 仍保留：正式 4v4 规则和主持文案由运维脚本、单元测试共同引用。
- `debate-prototype`、Storybook fixtures 和 MSW handlers 仍保留：它们是 UI 状态测试目录，不是生产业务分支。
- 28 个 migration 仍保留：已发布迁移不可删除或重写；新变更只能追加。
- Agent/ASR/TTS 的分层模块未合并成“大文件”：它们分别承载协议、连接、音频解码和 MatchActor 回调，合并会破坏取消/重试边界。

## v1.0 数据边界

提交到 GitHub 的内容只有代码、公开资源、迁移、测试、脱敏配置模板和部署教程。生产数据库、用户/比赛数据、音频、日志、密钥和管理员密码只存在服务器受保护目录；本机 `api.md` 和 `.env` 永不提交。

## 证据

- Core：154 个非集成测试通过；Jobs：19 个非集成测试通过。
- Web：157 个单元测试通过；Lint、TypeScript、Pyright、Ruff、Prettier、OpenAPI 契约和生产构建通过。
- Node 工具质量测试：原生对话框、资源、UI 对比度和构建隔离门禁通过。
- 真人 180 秒 ASR、11 音色盲听、五场并发和 50 路 LLM 仍属于真实环境验收，不在本次代码整理中虚报完成。
