## 整理修正

- 隔离未发布的Core、Prompt和模拟器候选；保留其私有原件及失败记录。
- 删除64个指向外部临时目录的废弃Makefile链接，归档原始个人记录，压缩维护日志。
- 将历史部署测试改为受审公开AST夹具；补齐测试导入路径，避免依赖本地缓存。

完整候选树与Git历史完成密钥扫描及逐项复核；命中项均为明确测试假值或公开源文件SHA，未留未处理的真实凭据命中。扫描不等于通用匿名化保证。
