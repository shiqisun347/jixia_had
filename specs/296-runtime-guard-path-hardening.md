# Spec 296 — 运行时 cgroup 路径异常闭环

- 版本：v2.0
- 状态：本地实现完成，待受保护发布
- 日期：2026-10-13
- 依据：Spec 295 审计复核发现符号链接循环可从 `Path.resolve()` 泄漏异常。

## 范围与验收

- cgroup 白名单读取遇到符号链接循环、解析失败、越界或权限错误时统一返回
  `unavailable`，不泄漏路径或原始文件内容。
- 增加循环链接回归，保持正常文件、缺失文件、`max` 和 OOM 计数语义不变。
- 不写 cgroup/systemd/数据库，不改变发布门禁默认值。

## 回滚边界

仅回滚路径异常捕获和对应测试；不影响运行时服务、数据库或比赛状态。
