# v2.1 实验配置准备与真实模拟验收

> 状态：已完成  
> 日期：2026-08-22  
> 依据：已批准需求、Specs 201-203、用户对 C7/Agent/匿名映射和模拟测试的授权

## 1. 目标

在不把模拟数据混入正式研究结果的前提下，固定 C7、六个 Agent、匿名账号及队伍映射，
并在服务器执行真实供应商并发和生产形态模拟验收。

## 2. 固定输入

- C7：`知识付费能不能缓解年轻人的压力`；正方“能缓解”，反方“不能缓解”；来源为
  CEDAR 数据中的 2019 华语辩论世界杯麦吉尔大学 vs 香港中文大学场次。原 JSON 没有
  独立 CEDAR ID，继续保存空值，不用数组序号伪造。
- T01-T06 依次绑定：乾元、坤元、慎思、破阵、见微、观澜。六者必须均为 ENABLED，
  使用同一模型，音色不同，语速保持既有配置。
- T01=`P01-P03`、T02=`P04-P06`、T03=`P07-P09`、T04=`P10-P12`、
  T05=`P13-P15`、T06=`P16-P18`；专家为 `E01-E03`。

## 3. 服务器准备

- 使用 Core service 创建 C7、P01-P18/E01-E03、模拟 DRAFT batch、6 队 roster 和
  18 场正式 + 3 场训练排表，以验证真实生产数据库约束。
- 模拟批次 code 必须以 `SIM_` 开头。默认保持 DRAFT；需要真实入房模拟时才显式发布，
  测试完成后立即停用，不纳入正式研究导出或排行榜。
- 一次性密码只允许写入服务器 root-only 文件，脚本只输出路径和计数。真实姓名对照表
  由研究者线下补充，不进入 Git、比赛记录或默认导出。

## 4. 真实模拟验收

- 发布前只读 preflight：四服务、2.1.0、0030、健康接口、实验开关和零活动比赛。
- 单链路：TTS -> ASR、LLM、AI 裁判、LiveKit。
- 并发链路：5 路 TTS、5 路 ASR、5 路 LiveKit 和 50 路短 LLM，输出成功数、失败数及
  P50/P95/最大延迟，不保存模型正文、Prompt 或音频。
- 仓库门禁：格式、Lint、类型、单元、数据库集成、Storybook、Playwright、契约和构建。
- 真人麦克风、蓝牙/噪声恢复和至少 10 人音色盲听不能由合成模拟替代，仍单列现场证据。

## 5. 回滚与停止条件

- 任一 provider 出现错误、数据污染或权限泄漏时保持实验开关关闭并停止后续发布。
- 模拟批次通过停用退出；不删除实验事实、不回滚 migration。
- C7 或账号创建成功后保留供正式配置复用；模拟凭据文件由管理员安全交付或轮换。

  展示名不会被覆盖。初始凭据仅写入服务器 root:root、`0600` 文件，未进入终端或 Git。
