# 165 项目知识基线与运维参考

状态：本机文档完成，待生产连接后补充服务器实测证据

## 目标

建立一份不含敏感凭据、可在后续修复和发布前快速复核的项目知识基线。内容只整理当前 v1.0 事实来源、已实现约束、代码入口、验证证据和未完成门槛，不替代 PRD、TechDesign、Spike 或 OpenAPI 生成契约。

## 范围

- 记录 Core、Jobs、Web、Contracts、PostgreSQL、LiveKit 和 systemd/Caddy 的职责边界。
- 记录比赛状态、计时、掉线重连、媒体在线和外部回调的不变量。
- 记录当前工作树与生产证据的区别，以及发布、回滚和测试门禁。
- 不读取或复制 `api.md`、`.env`、数据库、音频、日志、token 或任何真实凭据。

## 验收

- 新会话只阅读本参考、`AGENTS.md`、事实来源和 `MEMORY.md` 即可定位主要模块和风险。
- 每个结论标明代码证据、自动化证据或生产证据类型；缺少生产访问时明确标记为待补。
- 文档变更不修改业务协议、数据库 schema 或部署数据。

## 回滚边界

本规格只增加文档；回滚只删除本规格文档，不回退任何业务源码、migration、duration 回填或服务器数据。
