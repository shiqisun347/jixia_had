# Spec 237：赛后完整记录审阅与完赛提醒

## 状态

已完成并正式发布（2026-08-30）。

## 范围

本规格取代 Spec 235 中与“整场体验先于发言审阅”有关的页面描述；Spec 236
确立的两类问卷独立关系保持不变。

- 比赛正常结束后，真人参赛者在比赛页收到一次可关闭的本场问卷提醒。
- 单场赛后任务返回双方全部已定稿发言的阶段、阵营、席位、发言者、顺序和时间信息。
- 服务端按当前标注进度控制正文可见性，前端不自行拼接公开文字记录绕过解锁。
- `/me/postmatch-surveys` 按比赛、阶段和发言顺序展示上下文，只标注用户自己的发言和本方 AI 发言。
- 账号级 AI 辩论体验问卷继续使用 `/me/ai-experience`，不参与单场提交或下一场门禁。

## 权限与解锁

- 普通用户只能读取自己的任务；任务不存在或用户不是该场真人参赛者时，不返回完整记录。
- 当前目标是按发言顺序第一段尚未完成 `q1`、`q2` 的可标注发言。
- 当前目标之前的已定稿正文可见；当前目标完成并保存 `q1` 后解锁自身正文；当前目标完成 `q2` 后推进到下一目标。
- 当前目标之后的正文保持隐藏；任务提交后全部正文可见。
- 可标注对象仅为 `HUMAN_SELF` 和同阵营 `TEAM_AI`。队友真人及对方真人/AI 只作为上下文。
- 已保存并导致正文解锁的 `q1` 不可被后续旧请求修改。

## UI

- 完赛提醒包含“填写本场问卷”和“稍后处理”；同一浏览器标签页关闭后不重复弹出，问卷入口和 Core 门禁继续存在。
- 页面顶部展示比赛、状态和标注进度；正文按阶段分组，当前阶段默认展开。
- 正反方采用稳定的蓝/红视觉标识；卡片显示顺序、发言者、席位、真人/AI 和时间。
- 未来发言只显示阶段进度提示，不展示正文；当前目标只展示当前一步的问题，避免一次堆叠全部题目。
- 移动端单列且无横向溢出；保存、提交和加载失败提供可操作反馈。

## 验收

- Core 测试覆盖双方完整记录、本方标注范围、前序/当前/未来正文边界、保存 `q1` 解锁、`q1` 不可改和非参与者隔离。
- Web 测试覆盖阶段化展示、逐步解锁、草稿恢复、最终提交、独立体验链接和完赛提醒去重。
- 通过 Core 相关测试、Ruff、Web 测试、类型检查、Lint、生产构建和桌面/移动端浏览器检查。

## 回滚边界

- 回滚仅移除新增任务投影字段、阶段化页面和完赛提醒。
- 不删除或改写任务答案，不修改历史 migration，不移除现有下一场门禁和个人体验问卷。
