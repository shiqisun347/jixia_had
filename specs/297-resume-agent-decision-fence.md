# Spec 297 — Agent 发言暂停恢复决策栅栏

- 版本：v2.0
- 状态：本地实现完成，待受保护发布
- 日期：2026-10-13
- 依据：Spec 258/272 复审发现 Bug 4 模拟器未真正验证旧 Agent 决策清理。

## 问题

Agent 发言中暂停后恢复为 `AGENT_PREPARING` 时，当前语音和中间文本会清理，但旧的
`agent_decisions`、`agent_hand_queue` 与 `agent_decision_round_id` 仍可能保留。旧决策
随后可能被迟到回调消费，导致恢复流程使用过期的自由辩论选择。

## 范围与验收

- 恢复 Agent 发言时清除旧 Agent 决策、手队列和决策轮次；随后由权威恢复流程重新建立
  当前机会，不依赖前端状态或本地倒计时。
- 将可靠性模拟器 Bug 4 改为真实断言，覆盖暂停前已存在决策、恢复后字段为空以及迟到
  旧决策不能改变恢复状态。
- 保持自由辩论选择中暂停的“保留当前队列”语义；只影响 Agent 正在发言/收尾并重建
  `AGENT_PREPARING` 的路径。

## 回滚边界

仅回滚恢复清理和回归测试；不修改数据库 schema、迁移、供应商协议或生产数据。
