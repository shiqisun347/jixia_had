## 目的

为 CHI 2027 论文的 Methodology 生成可直接纳入稿件的
`Experiment Platform` 小节、界面图、图注和无障碍替代文本。素材仅陈述已由
PRD、TechDesign、语音 Spike 和 Spec 201 支持的平台行为，不将未完成验收写成已通过。

## 范围

- 英文 CHI 风格小节及中文对照。
- 一张基于当前辩手页的自由辩论标注图，使用每方 `3 Human + 1 AI`
  的论文实验配置。
- 一张由实验批次管理与赛后机会级标注组成的双面板图。
- 一个可重现截图的 Storybook 状态，只组合已有组件和已批准实验事实。

## 不在范围

- 不修改比赛状态机、权限、计时、语音或媒体协议。
- 不创建生产账号、房间或比赛，不引入真实参与者数据。
- 不声称真人麦克风、五场并发、50 路 LLM 或 11 音色盲听已通过。

## 验收标准

1. Markdown 包含英文正文、英文图注、alt text 和明确分隔的中文对照。
2. 图像来自实际运行的当前 Web 组件，且不包含真实参与者身份或研究数据。
3. 辩论图清楚标注比赛上下文、双方阵容、当前轮次、举手/决策队列、双方时间、
   文字记录和辩手控制；后台图呈现实验管理与机会级标注闭环。
4. 文字与 Spec 201 的论文实验配置一致，并将“可见界面”与“后台事件记录”区分表述。
5. 目标 Storybook 测试、图像尺寸/链接和 Markdown 格式检查通过。

## 回滚边界

回滚时只删除本规格、`docs/paper/` 产物、本规格在
`specs/README.md`/`MEMORY.md` 的记录，以及
`PaperExperimentFreeDebate` Storybook 场景。不触及任何生产数据或比赛逻辑。
