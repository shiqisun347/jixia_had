# Spec 282：发布预检非终态比赛状态诊断

- 版本：v2.0
- 状态：本地实现完成，待受保护发布
- 日期：2026-10-13
- 依据：线上只读预检发现非终态比赛总数无法直接说明是暂停、运行还是恢复状态。

## 问题与范围

`preflight_v2_1.sh` 只输出 `active_matches` 总数。发布被阻断时，运维人员还要手工查询
数据库才能知道应先恢复还是终止哪一类比赛。扩展只读查询，按状态输出非终态比赛计数，
并在失败信息中保留脱敏状态摘要；不改变门禁条件、状态机、数据库数据或服务行为。

## 验收

1. 非终态比赛查询继续使用同一终态白名单，额外返回 `active_statuses` 映射。
2. 门禁仍要求总数为零；状态摘要只包含状态名和整数计数，不输出房间、用户或密钥。
3. QA 覆盖状态摘要字段和 JSON 解析，shell 语法与现有只读门禁保持通过。

## 回滚

仅移除状态分解字段、输出和测试，不影响既有数据库修复、资源护栏或 LiveKit 识别逻辑。
