# Spec 245：统一 LLM 模型切换为 deepseek-v4-flash-0731

## 状态

已发布：使用已授权的阿里百炼工作空间密钥完成模型切换和运行时流式验证。

## 范围

- 将启用中的 `ModelProfile.model_id` 统一切换为 `deepseek-v4-flash-0731`，覆盖 Agent 和 AI 裁判的后续请求。
- 保留每个模型资源已有的 `base_url`、加密 API Key、生成参数、并发和能力配置。
- 新建房间/实验在创建快照时使用新模型；已经开始或已经冻结的比赛继续使用原模型快照。
- TTS、ASR 和 LiveKit 不在本次切换范围内。
- 通过受保护的幂等运维脚本执行，默认先 dry-run，显式 `--apply` 才写库，并记录审计事件。

## 验收

- dry-run 只输出模型资源名称、旧/新模型 ID 和引用数量，不输出 URL、密钥或连接串。
- apply 后所有启用模型资源的 `model_id` 均为目标值，禁用资源不被修改。
- 已有活动比赛的模型快照不变；新建房间快照使用目标模型。
- 供应商探针成功后才允许正式实验继续启用；失败按现有暂停语义处理，不自动切换供应商。
- Core 相关测试、类型检查、Lint、构建及数据库迁移检查通过。

## 回滚

使用脚本 `--model-id <旧值> --apply` 将启用资源恢复到切换前的模型 ID；不得修改历史比赛快照或执行数据库 downgrade。
