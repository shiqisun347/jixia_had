# 208 全局资源与系统设置实现细则

> 版本：v2.1  
> 状态：已完成并验证  
> 批准依据：用户要求按五阶段分别编写并批准规格后持续开发、测试（2026-08-22）  
> 依赖：207  
> 本阶段已批准，但必须在 207 验收后开始实施。

## 1. 目标

在 207 的后台基础上完成模型、音色、辩题、用户和系统设置的可用 CRUD，明确全局资源生命周期、引用保护和审计语义。

## 2. API 与数据边界

- 复用现有 OpenAPI/Pydantic 契约，新增接口必须先进入 Core 路由和 `packages/contracts`，Web 不手写 DTO。
- 不修改已发布 migration；确需持久化的新设置追加 migration，并为旧数据提供默认值。
- 所有写操作在事务提交后写审计记录；失败事务不产生成功审计。
- 列表接口支持状态、更新时间、引用状态和游标/分页，详情接口按 ID 查询。

## 3. 资源操作

### 模型

- 创建/编辑：名称、模型 ID、Base URL、启用状态、并发上限和参数能力 Schema。
- API Key 轮换为独立动作，响应只返回一次性确认信息，不回显旧值。
- 连接测试覆盖普通、流式、首 Token 和结构化输出；测试结果变更后自动失效。
- 被 Agent、AI 裁判或历史快照引用时禁止删除，只能停用。

### 音色

- 创建/编辑：供应商、voice ID、名称、头像键、速率档位和校准状态。
- 试听/校准是后台任务或明确异步状态；供应商、rate、pitch、instruction 变化使旧校准失效。
- 被 Agent 或主持人引用时禁止删除；停用前显示影响范围。

### 辩题

- 全局辩题可创建、编辑、停用和按来源查询；显示文本与正反立场使用稳定 ID 关联。
- 赛制、批次和普通房间只能引用或创建私有快照，不直接写回全局内容。
- 有历史比赛引用的辩题不物理删除；历史快照永不改写。

### 用户

- 延续 207 权限和密码会话规则；新增用户操作不允许绕过 Argon2id、冻结和审计规则。

## 4. 系统设置

只提供真正的全局运行参数：日志保留期、临时 DEBUG 开关及截止时间、全局上传限制等。每项设置必须显示作用范围、生效时机和是否影响已发布快照。

## 5. 验收

- 每类资源完成列表、创建、编辑、停用/删除保护、详情抽屉和错误恢复。
- 模型/音色引用保护、API Key 脱敏、辩题私有快照边界有 Core 测试。
- 管理员所有写操作在 AuditLog 可追踪，普通运行日志不泄露敏感字段。
- 空库与既有数据测试通过；无 migration 时执行 `alembic check`。

## 6. 回滚

关闭新增资源操作入口即可回滚；保留已写入的资源和审计数据，不删除历史记录。若新增 migration，回滚只停用读取新字段的代码，不降级生产数据库。

## 7. 实施增量

- 追加 migration `0031_model_capability_schema`，为全局模型保存代码声明的能力 Schema；旧模型使用空对象默认值，既有调用参数和比赛快照不变。
- 模型创建/编辑/响应已携带 `capability_schema`，后续 Agent 参数表单和发布校验只允许使用该 Schema 声明的字段。

## 8. 实施证据（2026-08-23）

- 追加 `0031_model_capability_schema`、`0032_system_settings`、`0033_voice_calibration_status`；模型能力范围、全局运行设置和音色校准状态均有默认值与约束。
- 模型编辑使用 Temperature/Top P/最大 Token 数的结构化控件；PATCH 不再接受 API Key，独立轮换接口只返回末四位确认信息并写审计。
- 音色参数变化标记为 `STALE`，试听成功/失败分别记录 `READY`/`FAILED`；活动比赛引用的模型、音色、Agent 停用和批量停用由 Core 阻止。
- 系统设置仅允许日志保留期、24 小时内临时 DEBUG 截止时间和全局上传上限；写入与审计同事务，过期 DEBUG 读取时自动关闭。
- 验证通过：Core 非集成测试 276 项、Jobs 非集成测试 23 项、Web 单元测试 181 项、完整 Storybook 89 项，Ruff、ESLint、Pyright、TypeScript、OpenAPI 契约检查和 34 路由生产构建通过；后台视口与交互证据保留在本规格和 207/210。
- 独立 PostgreSQL 16.10 已从空库执行 0031–0036 完整迁移链；`alembic check` 返回无待生成操作，数据库门禁通过 Core 28 项、Jobs 2 项。本轮未部署。
