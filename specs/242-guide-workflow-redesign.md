# Spec 242：使用指南工作流重设计

- Version: v2.0
- Status: Implemented locally
- Date: 2026-08-31

## Goal

重做 `/guide`，准确说明当前正式 4v4 规则、真人参赛流程、观众入口、暂停恢复、声音控制和两个独立的赛后问卷入口。指南只改变 Web 展示，不改变比赛状态机、Core API、数据库或实时音频协议。

## Requirements

- 默认展示真人辩手流程，并可切换观众和管理员简版视图。
- 标准规则示例为正反方一辩各 90 秒、自由辩论双方各 6 分钟、正方先开始、单次最多 30 秒；明确实际房间以冻结规则快照为准。
- 说明设备检测、手动开始发言、自由辩论申请、暂停恢复、浏览器本地静音和异常处理。
- 明确单场赛后发言问卷与账号级 AI 体验问卷分离；单场问卷提交是下一场正式比赛门禁。
- 桌面端提供快速目录，移动端单列且无横向溢出。

## Acceptance

- 页面不再出现过期的固定九阶段、反方先开始或不存在的二辩/三辩/四辩阶段描述。
- 角色切换、关键入口和问卷链接可访问；未登录访问仍遵循现有认证边界。
- Web 单测、类型检查、Lint、Storybook、生产构建和桌面/移动截图检查通过。

## Rollback

恢复 `apps/web/src/app/guide/page.tsx` 及同目录工作区组件和测试即可；不涉及数据库迁移或服务端回滚。
