# Spec 273 — Provider 流收敛与发布门禁修复

- 版本：v2.0
- 状态：已于2026-10-15随完整流程版本受保护发布，当前标准门禁与生产预检通过；真实压力验收仍独立进行
- 日期：2026-10-12
- 依据：Spec 272 的故障注入审计及现有 Provider/TechDesign 失败语义。

## 目标

修复供应商持续发送心跳、流提前结束时 Agent/ASR 任务不收敛的问题，并恢复发布门禁
与前端 lint 的可信度。比赛状态仍由 Core/MatchActor 权威推进，不通过前端倒计时或
静默切换供应商解决故障。

## 范围与验收

1. LLM SSE：首正文使用总预算，注释/空白/heartbeat 不得重置总预算；正文出现后必须
   观察明确的正常结束标志，截断 EOF 收敛为稳定 Provider 错误；保留取消、重试和
   TTS 回调错误传播语义。非 2xx 错误响应的诊断 body 读取也受同一首正文绝对截止的
   剩余时间约束；静默或慢速持续错误体不能绕过截止。超时保留既有
   `llm_provider_failed` 和有界不可用诊断，不延长预算或新增重试。
2. ASR WebSocket：sender 未完成时增加有界的整段任务预算；持续 heartbeat 不能无限
   延长任务；超时应关闭/隔离 socket 并返回稳定 `asr_audio_timeout` 或现有等价错误。
3. 发布检查和管理员 CLI 必须验证当前迁移 head，不得固定过期 revision；不修改历史
   migration。Web lint 的 React Compiler 错误必须消除，保持表单提交和幂等门禁语义。
4. 为每一项新增回归/故障注入测试；运行 Core/Jobs/Web 单元、类型、Ruff、契约、
   Storybook、浏览器和仓库生产构建。集成 PostgreSQL 若环境不可用，必须如实标记。
5. 使用合成内容，不记录密钥、完整用户发言或供应商原始响应；不在生产注入故障，
   不修改生产比赛数据。
6. 修复门禁发现的历史测试漂移：音色归档按 Spec 263 保留规则内启停偏好，并验证
   有效可用性为 false；正式 4v4 和成员组合数据库夹具自行创建管理员，不依赖测试
   顺序或预先种子数据。Storybook/浏览器断言必须覆盖当前产品流程，不能降低验收范围。
   pnpm 生命周期脚本策略逐项声明拒绝非必要安装脚本，恢复仓库命令可执行性。
   CI 数据库集成必须显式创建并传入独立本地 QA 数据库，不能缺少
   `TEST_DATABASE_URL` 或复用应用库；保持新增故障夹具的专属库保护。
   旧语音白盒测试夹具使用正确的 Pydantic SecretStr 类型并禁用 dotenv；显式标记
   测试中有意访问的私有接口，其他类型错误仍须修正，不能放宽生产身份栅栏。

## 非目标

- 不更换供应商、模型、音色或媒体协议。
- 不调整比赛状态机、计时起点、重试次数和权限语义，除非为上述收敛所必需且有回归证据。
- 不修改已发布 migration；若需要数据库变更，另建规格并追加 migration。

## 回滚边界

仅回滚本规格新增的适配器、lint、preflight 和测试文件；保留现有生产数据、比赛记录、
Provider 诊断及历史迁移。发布前必须保留源文件回滚副本。

## 2026-10-13 错误体截止与 CI 隔离补充证据

- 非 2xx 诊断错误体共用首正文绝对剩余预算。10 项回归通过；原样 10 秒常量的真实
  loopback HTTP 静默/慢速错误体分别约 10.006/10.008 秒返回，原 llm_provider_failed
  保留，实际 FD 已关闭。两个短预算 socket 场景再重复 20 轮共 40 次通过，兼容正常
  FIN 与 unread-body TCP RST，未降低最终清理前 FD 断言。
- CI 创建独立专属 QA 库，并为 pnpm test:db 显式配置不同于应用库的 TEST_DATABASE_URL。
  本地标准命令实际串行 Core 126、Jobs 5 项集成通过；未声称 GitHub CI 已执行。
- 旧语音白盒夹具使用 SecretStr、禁用 dotenv、补齐 Optional/JSON 类型和有限 PyAV
  stub 注释；56 项通过，定向 Pyright 原 61 个错误已归零。生产身份栅栏未放宽。
- 最新全量与边界见 MEMORY.md 的“Provider 诊断事务、迟到结果与恢复闭环”；本轮仍未
  生产写入或发布，没有把本地 HTTP 复测当成真实供应商压力。
