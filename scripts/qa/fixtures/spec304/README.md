# Spec304 历史回归夹具

这些文件用于离线测试历史部署恢复和资源前检的保护语义，不提供生产安装、恢复或资源修改入口。

- `release_recovery_ast.py` 保留历史恢复辅助函数与异常处理分支。安装主体替换为无操作的 `pass`；运行依赖仅为不可调用的 `None` 占位。测试只提取 AST，以自有临时文件和模拟服务执行，验证备份损坏、活动比赛、停止失败、迁移保留和独立重启等边界。
- `resource_preflight_ast.py` 保留历史 `save`、只读 `plan` 和调用顺序 `main`。`configure` 仅保留原迁移前置断言，然后拒绝执行；测试成功路径显式注入模拟修改回调，验证只读前检和私有快照先于修改。

没有真实主机、凭据、审批或运行配置。正常测试不需要私有归档目录；这些历史夹具也不能替代当前 v2.0 安装工具、数据库恢复验证或生产验收。
